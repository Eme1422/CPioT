## 📌 Descripción del Proyecto
Esta aplicación web interactiva desarrollada con **Streamlit** y **Python** procesa y visualiza las mediciones históricas registradas por un tótem IoT experimental equipado con un microcontrolador ESP32 y un sensor óptico MAX30102.
